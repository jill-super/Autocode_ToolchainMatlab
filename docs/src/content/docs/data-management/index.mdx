The `Data_Management` area is the foundation everything else builds on. It defines **what can be said** about a component (the `DataDict.*` vocabulary), **how values are typed** (`bt.*`, `dt.*`), and **how objects become dictionary text** (helpers + `String` methods).

## The core idea

```matlab
c = DataDict.Calibration;   % 1. pick a class (the "what")
c.EngDT = dt.s16;           % 2. pick a type (the "how")
c.EngVal = 10;              % 3. give it a value
```

Each object validates its own properties on assignment (ranges, allowed values, naming patterns) and knows how to render itself into dictionary source through its `String` method. `CreateDD` simply collects the workspace objects and concatenates their rendered text; `VerifyDD` re-parses that text and checks the rules again plus cross-checks against the model.
