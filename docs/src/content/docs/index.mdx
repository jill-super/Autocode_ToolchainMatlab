A Model-Based Design toolbox for Simulink that treats the **data dictionary as the contract**: interfaces are declared once as typed objects, generated into component dictionaries, verified automatically, packaged with reports, and validated with MIL/SIL.

## The three pillars

- **Data management** — `DataDict.*` classes for signals, parameters, runnables and diagnostics; `bt.*` base types; `dt.*` fixed-point types; helpers that render values into dictionary text. Start at [Data management](data-management/).
- **Design tools** — `CreateDD`, `VerifyDD`, the `STool` hub, keyword checks, and report/packaging generators. Start at [Design tools](design-tools/).
- **Testing tools** — the `MIL` GUI, `Run_SIL`, test-definition management, report pipeline, and traceability bridges. Start at [Testing tools](testing-tools/).
- **Reusable libraries** — vetted EA3/EA4 math, fixed-point, interpolation, filter, IMC and NVM blocks. Start at [Simulink libraries](libraries/).
