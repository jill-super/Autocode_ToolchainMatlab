The `Libraries` area ships **26 Simulink libraries** of vetted, code-generation-ready blocks. Build FDD subsystems from these instead of raw Simulink blocks wherever an equivalent exists — the test tools (`NxtrMdlChkr`, `NxtrMaskList`) know these blocks and their coverage rules.

## Family map

| Library root | File | For |
| --- | --- | --- |
| EA3 | `EA3_Library/NexteerUtilities.slx` (+ C/S-function sources) | That program type's interpolation, fixed-point and math blocks |
| EA4 | `EA4_Library/NxtrMdlUtilities.slx` + `Math`, `FixdPt`, `Intrpn`, `Fil`, `IMC` | Limiters, conversion, interpolation, filters, communication — see [EA3 & EA4 blocks](ea3-ea4/) |
| NVM | `NvM_Library/NxtrNvM.slx` (+ HTML help) | Non-volatile-memory client blocks — see [NVM & development](nvm-dev/) |
| Development | `Development Library/DevLib.slx` | Prototyping blocks — same page |
| Top | `NxtrLib.slx` + `slblocks.m` | Library browser entry point registering the families |
